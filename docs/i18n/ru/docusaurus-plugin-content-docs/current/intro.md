# Введение

Добро пожаловать в документацию **NeoWatch API**.

NeoWatch API предоставляет данные о фильмах и сериалах, стриминговые плееры, пользовательские функции: избранное, отслеживание просмотров.

## Базовый URL

```
https://api.neome.uk
```

## Возможности

- 🎬 **Фильмы и сериалы** — Полные метаданные из TMDB
- 🔍 **Поиск** — Текстовый поиск и расширенная фильтрация
- 📺 **Плееры** — Несколько стриминговых провайдеров (Alloha, Collaps, CDN)
- ⭐ **Избранное** — Управление избранным
- 📌 **Посмотреть позже** — Список для просмотра позже
- 🔄 **Синхронизация** — Синхронизация прогресса между устройствами
- 🔐 **Аутентификация** — Neo ID SSO (OAuth 2.0 + OIDC)

## Формат ответа

Все ответы следуют стандартному формату:

```json
{
  "success": true,
  "data": { ... }
}
```

Ошибки:

```json
{
  "success": false,
  "error": "описание ошибки"
}
```

## Поддержка языков

Все эндпоинты контента принимают параметр `?language=`:

| Код | Язык |
|-----|------|
| `ru-RU` | Русский (по умолчанию) |
| `en-US` | Английский |
| `uk-UA` | Украинский |
| `ro-RO` | Румынский |
| `be-BY` | Белорусский |

## Пагинация

Эндпоинты списков принимают `?page=` и возвращают:

```json
{
  "items": [],
  "page": 1,
  "totalPages": 10,
  "totalResults": 200
}
```
